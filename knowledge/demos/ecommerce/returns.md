# Returns & Refunds

## Return window

Returns are accepted within 30 days of delivery, as long as the item is unused (unwashed, with its original tags). So an item can still be returned after 10 days. The assistant can start a return for you.

## Starting a return

Go to My account → Orders and choose Return item, or ask the assistant to start a return for you. Return shipping is free with the prepaid label.

## Refunds

Refunds go back to your original payment method within 5–7 business days after your return arrives at our warehouse.

## Exchanges

Need a different size? You can exchange an item for another size for free within the same 30-day window.

## Items that can't be returned

Underwear, earrings, gift cards and items marked as final sale can't be returned.
